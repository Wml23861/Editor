# 第三方番茄资深编辑长期审稿项目

本项目是**完全独立的第三方审稿项目**，与小说项目无任何代码、配置、Git、Skill、CLAUDE.md 继承关系。

## 读取边界

- ✅ 唯一允许读取：`E:\心界\yinianchengshijie\novel\正文`（只读）
- ❌ 禁止读取小说项目其他一切文件（设定、大纲、笔记、CLAUDE.md 等）
- ❌ 禁止修改小说正文

## 目录结构

```text
E:\心界\编辑\
├── .claude\skills\reader\SKILL.md   # /reader 命令 Skill（审稿规则全集，技术路径保留英文）
├── 追踪总账.md                       # 唯一跨章汇总：读者状态/期待/弃书风险/问题/重复模式/优秀内容
├── 章节\                             # 每章一个文档：第001章_章节名.md
│   │                               #   （文档头速记 + 26节报告 + 本章追踪变更，不拆分）
│   └── 复审\                         # 修改后复审存档：第X章_复审.md
├── 专项审查\                         # 追读/弃书/总评/AI/哲理/主角/人物/剧情专项存档
└── 阶段报告\                         # 十章阶段报告 / 五十章责编报告
```

**分工原则：细节在章节文档，状态在总账。** 本章发生了什么（新期待、新风险、好段落）写在该章文档的「本章追踪变更」里；这个期待悬空几章了、这个问题第几次出现，只看《追踪总账.md》。

## 使用方法

在对话中输入：

- `/reader 1` 或 `/reader 第1章` — 审指定章节
- `/reader 本章` — 审正文目录中最新一章
- `/reader 继续` — 审当前位置的下一章
- `/reader 追读` / `/reader 弃书` / `/reader 总评`
- `/reader 十章报告` / `/reader 五十章报告`
- `/reader 重复` / `/reader ai` / `/reader 哲理`
- `/reader 主角` / `/reader 人物` / `/reader 剧情` / `/reader 期待`
- `/reader 修改后复审` — 正文修改后重新进行读者体验审查
- `/reader 最严格审稿` — 最高强度模式（可与章节命令组合，如 `/reader 最严格审稿 第3章`）

## 自动机制

- 每次审稿：更新 `追踪总账.md` 对应板块
- 同类问题连续 3 章出现 → 升级为结构性问题
- 读者期待 >10 章未回应 → 悬空风险上调；>20 章 → 高风险点名
- 完成每 10 章 → 提示生成十章报告；每 50 章 → 责编报告
